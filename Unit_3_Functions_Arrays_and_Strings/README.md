# Unit 3 — Functions, Arrays and Strings

Examples cover function declaration/definition/call, arguments and return values, call by value, pointer-based reference-style modification, recursion, one- and two-dimensional arrays, searching, sorting, matrix operations and strings.

**String safety:** `gets()` is unsafe and was removed from the C standard. Use `fgets()` instead. Functions such as `strrev()`, `strupr()` and `strlwr()` are non-standard; use portable logic or implement the transformation explicitly.
