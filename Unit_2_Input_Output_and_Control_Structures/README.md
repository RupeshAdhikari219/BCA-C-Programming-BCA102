# Unit 2 — Input/Output and Control Structures

Covers formatted I/O (`printf`, `scanf`), decision making (`if`, nested conditions, else-if, `switch`), loops (`for`, `while`, `do-while`, nested loops) and jump statements.

`getchar()` and `putchar()` are standard character I/O functions. `getch()`, `getche()`, `putch()` and `clrscr()` are compiler-specific legacy console functions and are intentionally not used in portable examples.
